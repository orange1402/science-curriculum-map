# 自然課綱・小中高縱向探索

以108自然科學領域課綱整理生物、物理、化學與地球科學的學習內容及學習內容說明。

網站：https://orange1402.github.io/science-curriculum-map/

- 84 個概念單元、779 條學習內容，涵蓋國小Ⅱ、Ⅲ、國中Ⅳ、高中必修及加深加廣選修。
- 學習內容與說明完整並列；科目及單元分類置於上方。
- 各學段以連結性排序：相連概念群優先，未連結條目置後；同群內保留 Excel 順序。
- 沒有直接關係的學段可保持空白，不強制串成完整主線。
- 連結理由、深化重點及範圍界線可點選連線查看。

## 用 Excel 調整

1. 網頁展開「Excel 編輯與匯入」，下載範本。
2. 在「縱向連結」調整起點與終點，或將「啟用」改為「否」取消連線；在「單元條目」增減卡片。
3. 儲存為 `.xlsx`，在網頁匯入並按「套用資料」。

匯入在瀏覽器內處理，會檢查代碼、重複資料及引用關係；遇到錯誤會保留既有資料。
套用資料只保存在目前瀏覽器的目前網站網址下，不會自動同步其他裝置或修改 GitHub 內容。
原 Sites 網址中的本機匯入資料也不會自動搬到 GitHub Pages，請重新匯入保存的 Excel。

## 網站更新與檢查

`docs/` 是完整的靜態網站，使用相對路徑，無須安裝套件或後端。
GitHub Pages 設定為 **Deploy from a branch → main → /docs**；更新 `docs/` 並提交後即會重新部署。

以 Node.js 執行資料及排序檢查：

```sh
node check.mjs
```
